# Half-Life 2 (HEV Suit) — peon-ping / OpenPeon pack

HEV-suit UI sounds from Half-Life 2 for [peon-ping](https://github.com/PeonPing/peon-ping)
agent notifications: suit charger, HUD blips, and alert buzzes.

## Install

```bash
peon packs install hl2
peon packs use hl2
```

Or locally from a checkout:

```bash
peon packs install-local .
peon packs use hl2
```

## Categories

| Category | Sounds |
|---|---|
| session.start | HEV battery pickup |
| task.acknowledge | HUD select, weapon select, HUD off, button release, flashlight |
| task.complete | charge complete, med charge, medkit |
| task.error | HEV warning, selection denied |
| input.required | incoming message, friend online |
| resource.limit | no charge available |
| user.spam | HUD rollover |
